# Examples

All committed example data is fictional. Names, organizations, events, sources, interactions, and outcomes are synthetic and use reserved `example.org` URLs. They illustrate the framework and do not create requirements.

The [Riverbend fictional graph](fictional/README.md) contains at least one record for every public schema. Run `python3 scripts/validate.py` to validate schemas, records, and stable-ID links.

Do not contribute real personal contact information, private relationship notes, inferred sensitive traits, or unsupported claims about real people. Use a governed private overlay for authorized real-world practice.
