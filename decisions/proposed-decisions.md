# Proposed and deferred decisions

These items do not block the inspectable framework architecture, but any item marked as a required [v1.0.0 release criterion](../project/specifications/v1.0.0-release-criteria.md) blocks the final release claim until completed.

| Decision | Initial position | What would resolve it |
| --- | --- | --- |
| Public repository host and slug | Local repository only | Owner selects and authorizes publication target. |
| Additional maintainers | Brad Groux is the sole founding steward | Named people accept documented responsibilities. |
| Private security and conduct channel | Use an already trusted private channel | Owner publishes an appropriate monitored address or service. |
| Release signing and cadence | No signing or fixed cadence | Maintainers approve a release policy and key custody plan. |
| Private overlay tooling | Contract only; no preferred vendor | A separate implementation proposal evaluates privacy, access, retention, and portability. |
| Independent review | Initial AI reviews and repository-local remediation/code review completed; qualified human/domain reviews remain required | Post-fix AI reviews and qualified ethics, privacy, accessibility, and domain reviews complete and receive accountable dispositions. |

Implementation assumptions are recorded in the [grill review](../project/discovery/grill-with-docs-review.md). None may override a locked decision.
