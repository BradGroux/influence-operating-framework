# 0004: Adopt Open Framework Commons v1.1.0

- **Status:** Accepted
- **Date:** 2026-08-22
- **Decision owner:** Brad Groux

## Context

Open Framework Commons v1.1.0 recognizes Focus Operating Framework as the
fifth equal, independent product in Commons scope and updates shared-scope
checks accordingly. Its nine shared principles and research guidance are
unchanged from v1.0.0. Its boundary changes add Focus to the complete product
list and clarify that guidance for directing personal focus remains
product-local.

The reviewed release is annotated tag
[`v1.1.0`](https://github.com/BradGroux/open-framework-commons/releases/tag/v1.1.0),
tag object `79e5f06dab46f262cad1d1daf7840e683ffc3880`, peeling to release
commit
[`f25a2b89b4aed95984fd235e2e229efe52c125d8`](https://github.com/BradGroux/open-framework-commons/commit/f25a2b89b4aed95984fd235e2e229efe52c125d8).
The previous v1.0.0 pin was
`a0f0d384e9010a65d1a21a324b4c912433d5e031`.

## Options

1. **Remain on Commons v1.0.0.** This requires no local change but leaves
   Influence outside the current five-product shared-applicability review.
2. **Adopt Commons v1.1.0 automatically.** This follows the upstream release
   but violates Influence's requirement for a separate local decision.
3. **Review and adopt the exact v1.1.0 release.** This recognizes Focus in the
   shared scope while preserving Influence's independent authority.

## Decision

Adopt Open Framework Commons v1.1.0 through option 3.

- Adopt all nine unchanged shared principles and all shared boundaries.
- Recognize Focus Operating Framework as the fifth equal, independent product
  in Commons scope and include it in future shared-applicability review.
- Keep Influence's concerns, method, terminology, examples, research,
  governance, roadmap, implementation choices, and releases product-local.
- Continue to defer Mission Control, community-extension topics, and guidance
  owned by other ecosystem products unless separately accepted here.
- Record no deviation. Influence's stronger human-judgment, consent,
  communication-boundary, and external-action requirements remain compatible
  local guidance.

## Consequences

- `README.md` and `GOVERNANCE.md` identify the exact current Commons release.
- Decision 0003 and the v1.0.0 review records remain unchanged as historical
  evidence; this decision supersedes only the active Commons pin.
- Commons stewardship files, validation tooling, and release processes remain
  Commons-local and are not copied into Influence.
- No canonical Influence concern, practice move, responsible-practice rule,
  measurement dimension, glossary term, or example changes.
- Later Commons releases still require a separate adoption, deferral, or
  deviation decision.

## Review implications and limits

This documentation-only adoption adds no personal data, contact action,
automation, implementation requirement, or new accessibility surface. Existing
privacy, consent, safety, and accountable-human-judgment requirements remain
unchanged.

Remaining on Commons v1.0.0 was a viable alternative. The decision owner chose
the exact v1.1.0 adoption so future shared proposals include Focus explicitly.
No dissent was recorded. Whether a later Commons release remains compatible is
unresolved until that exact release receives a separate local review.
