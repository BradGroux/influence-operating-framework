# Practitioner profiles

Profiles adapt one canonical framework to a mission. They declare goals, boundaries, ecosystems, channels, assets, research questions, capacity, and review plans; they do not create a separate framework.

- [Brad Groux](brad-groux/profile.md) is the first owner-supplied implementation profile. It contains only context supplied in the build brief and is not independent research.
- [Riverbend Learning Collective](riverbend-learning-collective/profile.md) is entirely fictional and demonstrates a noncommercial community education mission.

Real private notes, contact details, consent records, and sensitive evidence must live outside the public repository in a governed private overlay. Profile files here are public-safe declarations only.
