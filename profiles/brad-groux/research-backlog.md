# Research backlog

This backlog defines questions; it does not assert answers or authorize outreach.

1. Inventory current talks, workshops, demos, articles, repositories, recordings, and rights.
2. Identify which assets have current evidence, accessible formats, and reusable modules.
3. Select one bounded ecosystem question for each quarter based on capacity and mission.
4. Verify public event, CFP, podcast, community, and media opportunities from primary sources.
5. Document current public roles before using any person or organization context.
6. Identify publicly requested contribution gaps that match existing expertise.
7. Establish a private-overlay tool and governance only through a separate approved decision.
8. Define a public-safe baseline for contribution, relationships, learning, reach, and commercial outcomes.
9. Arrange independent ethics, privacy, accessibility, and domain review before a 1.0.0 maturity claim.

Every item may end as verified, rejected, deferred, no action, wait, or do not contact.
