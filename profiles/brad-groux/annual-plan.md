# Annual plan — initial operating outline

**Status:** Proposed profile plan, not an approved event or outreach calendar

## Direction

Use contribution-first experiments to learn which ecosystems, channels, and assets create meaningful value while preserving time for Digital Meld, open source, and community commitments.

## Quarterly loop

1. Choose one bounded ecosystem or audience question.
2. Verify one to three community needs from primary public sources.
3. Adapt or create one accessible reusable artifact.
4. Evaluate a small number of opportunities with narrative reasoning.
5. Engage only after human review and only when context supports it.
6. Fulfill commitments and publish public-safe lessons, including failure.
7. Update the profile, stop ineffective work, and select the next experiment.

## Measures

Review contribution, relationship continuity, learning, relevant reach, and aligned commercial outcomes separately. Do not set contact-volume or follower-count quotas.

## Owner decisions still needed

Current capacity, specific quarterly priorities, private-overlay choice, public baseline, travel boundaries, and approved publication channels are intentionally not invented.
