# Ecosystem mapping

An ecosystem map explains a bounded field of contribution and relationship context. It is not a directory of people to contact.

## Map question first

Start with a question such as “Where can this practitioner contribute useful beginner-friendly accessibility resources in regional technology education?” State the mission connection, time horizon, geographic or domain boundary, privacy classification, and stop condition before collecting records.

## Graph model

The public record model supports people, organizations, ecosystems, events, relationships, interactions, opportunities, contributions, and evidence. Communities, media, newsletters, podcasts, platforms, projects, sponsors, and user groups may be represented as organizations with explicit `organization_type` values or linked through extensions when a specialized public schema is justified.

Edges are first-class relationship records. Every edge identifies its participants, relationship type, status, confidence, privacy, evidence, and review date. Co-presence, employment, follows, and mentions do not prove a personal relationship.

## Mapping procedure

1. Declare the map question and boundary.
2. Inventory existing authoritative records before searching.
3. Discover candidate node types from approved public sources.
4. Create evidence records before material claims.
5. Verify current roles and dates.
6. Add only edges that answer the map question.
7. Label inference and hypothesis; preserve contradictions.
8. Ask what is missing, what is over-collected, and what should remain private.
9. Review with a person who understands the ecosystem when practical.
10. Record next review date or expiry.

## Views, not master rankings

A graph may produce views for contribution, event preparation, learning, accessibility, community service, or partnership. A view filters the same evidence-backed graph for a declared purpose; it does not create a global score of human importance.

Useful view questions include:

- Which communities have requested help that matches current capacity?
- Which events connect multiple mission-aligned ecosystems?
- Which contributions could be reused or handed to emerging leaders?
- Which records are stale, uncertain, private, or marked do not contact?

## Quality and safety checks

- Every public node has a stable ID and fictional or source-authorized identity.
- Every material edge cites evidence and states confidence.
- No sensitive attribute is collected merely because it is discoverable.
- The map includes gaps and uncertainty, not only confident connections.
- The map can produce no action without being treated as incomplete.
- Views explain why a record is shown and never sort solely by reach.
