# Reviews

Release reviews evaluate the exact candidate commit from two independent
perspectives:

1. **Application review:** Can a practitioner understand and use the framework
   across realistic contexts without relying on hidden technical machinery?
2. **Adversarial framework review:** Are the concepts coherent, bounded,
   ethically responsible, and resistant to transactional or manipulative use?

Reviewers should evaluate the canonical framework before examples and should
not turn optional implementation choices into framework requirements.
