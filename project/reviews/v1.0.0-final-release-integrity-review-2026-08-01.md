### Minor

#### N-01: Diagram dependency claims omit the transient renderer

**Evidence:** `CHANGELOG.md:36-43`,
`project/reviews/v1.0.0-supplemental-review-disposition-2026-08-01.md:81-86`,
and `scripts/validate_mermaid.sh:18-23,38-42` at the reviewed commit.

The changelog says rendering dependencies were removed, and the supplemental
disposition says there is no package dependency (`CHANGELOG.md:36-43`;
`project/reviews/v1.0.0-supplemental-review-disposition-2026-08-01.md:81-86`).
No package manifest, lockfile, generated export, or committed dependency tree
exists, but the release check invokes pinned
`@mermaid-js/mermaid-cli@11.16.0` through `npx`
(`scripts/validate_mermaid.sh:18-23,38-42`).

**Action:** Narrow the claim to no committed rendering dependency or document
the transient pinned renderer. Do not add a package manifest or generated
assets merely to resolve the wording.

#### N-02: Repository-validation descriptions are broader than the checks

**Evidence:** `AGENTS.md:54-66` and
`scripts/validate_repository.py:36-56,121-147` at the reviewed commit.

Repository instructions say validation checks Markdown links, anchors, version
consistency, and the framework boundary (`AGENTS.md:54-66`). The validator uses
a defined inline-link pattern, checks that the version string occurs in three
release-facing files, requires the first line to be an H1, and tests a fixed
list of removed root paths
(`scripts/validate_repository.py:36-56,121-147`).

Current documents, links, anchors, versions, and paths pass. The issue is the
generality of the description rather than a broken release artifact.

**Action:** Narrow the description to the implemented structural checks or
expand the validator before claiming broader coverage.

#### N-03: Historical reports do not consistently include source evidence

**Evidence:** `project/reviews/README.md:18-30`,
`project/reviews/v1.0.0-supplemental-framework-coherence-review-2026-08-01-c.md:32-52`,
`project/reviews/v1.0.0-supplemental-misuse-resistance-review-2026-08-01-e.md:32-44`,
and `project/reviews/v1.0.0-supplemental-simplicity-scope-review-2026-08-01-f.md:29-68`
at the reviewed commit.

The standardized format requires repository-relative evidence
(`project/reviews/README.md:18-30`). Nine of ten historical independent reports
contain no source path, while the remaining report names
`framework/charter.md` without line evidence. Representative uncited findings
appear in the supplemental coherence, misuse-resistance, and simplicity reports
(`project/reviews/v1.0.0-supplemental-framework-coherence-review-2026-08-01-c.md:32-52`;
`project/reviews/v1.0.0-supplemental-misuse-resistance-review-2026-08-01-e.md:32-44`;
`project/reviews/v1.0.0-supplemental-simplicity-scope-review-2026-08-01-f.md:29-68`).

**Action:** In a bounded repository-maintenance correction, restore concise
`path:line` evidence against each report's reviewed commit without changing
verdicts, severities, finding substance, dissent, or limitations.
