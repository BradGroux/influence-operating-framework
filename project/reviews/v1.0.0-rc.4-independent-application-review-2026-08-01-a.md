The community sponsorship example demonstrates mission-led group use without
hidden machinery. The board examines purpose, permissions, financial pressure,

names the program director as the accountable actor and preserves decline as a

assistant neither selects contacts nor submits or extends the work
automatically (`examples/03-assisted-open-source-contribution.md:53-61`). The
example disclaims any required model, protocol, or automation system
(`examples/03-assisted-open-source-contribution.md:73-77`). These boundaries
match the canonical assisted-work standard
(`framework/responsible-practice-standard.md:92-111`).

their scenario-specific roles and formats do not create framework requirements
(`examples/README.md:3-10`).
