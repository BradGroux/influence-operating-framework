## Finding

### APP-RC2-MAT-001 — Placeholder rejection is incomplete

**Class:** Material
**Scope:** Repository-local

**Evidence**

- `project/migrations/portable-records-2-to-3.md:21` requires placeholder strings to be replaced with structured unknowns.
- `project/migrations/portable-records-2-to-3.md:38` claims that known text rejects common unknown placeholders.
- `schemas/common.schema.json:98-104` distinguishes permissive `nonEmptyString` from placeholder-rejecting `knownString`.
- `schemas/event.schema.json:12` uses permissive `nonEmptyString` for event name.
- `schemas/profile.schema.json:14` uses permissive `nonEmptyString` for profile mission.
- `schemas/contribution.schema.json:13` uses permissive `nonEmptyString` for the evidenced contribution need.
- `tests/test_schemas.py:790-801` checks placeholder rejection only through event `accessibility_summary`.

**Reproduction**

In separate disposable copies of the exact candidate, make one mutation at a time:

```json
{ "name": "TBD" }
```

```json
{ "mission": "unknown" }
```

```json
{ "need": "N/A" }
```

Then run:

```text
python3 scripts/validate.py --root <fixture> --only schemas --no-report
```

All three mutations exit 0 with `PASS schemas` and `PASS graph-references`.

**Impact**

A new adopter can satisfy portable validation while leaving an event identity, practitioner mission, or claimed contribution need unresolved. That defeats the structured-unknown discipline and allows validation to overstate whether the lifecycle has a meaningful mission, bounded subject, or evidenced need.

The prior rc.1 disposition addressed the specific accessibility-field reproduction but overstated the closure as general placeholder rejection.

**Smallest acceptance condition**

Audit portable fields whose semantics require a known value and apply `knownString` or equivalent placeholder rejection consistently. At minimum, reject the reproduced event name, profile mission, and contribution need mutations. Add a field-matrix regression test while retaining structured unknown objects only where the schema intentionally permits uncertainty.
